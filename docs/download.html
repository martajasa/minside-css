Download

Pilih metode instalasi yang paling cocok dengan workflow proyek Anda.

CDN (Fastest)

Cocok untuk prototyping cepat atau static website.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/minsidecss/minside-css@main/dist/minside.min.css" />
<script defer src="https://cdn.jsdelivr.net/gh/minsidecss/minside-css@main/dist/minside.min.js"></script>

NPM

Cocok untuk proyek yang memakai bundler (Vite, Webpack, Laravel Mix, dll).

npm install minside-css

// app.js / main.js
import "minside-css/dist/minside.css";
import "minside-css/dist/minside.js";

Manual Download

  • minside.css (readable source)
  • minside.min.css (production)
  • minside.js (readable source)
  • minside.min.js (production)

Versioning Notes

Untuk production, disarankan pin versi spesifik agar tidak terkena breaking change yang tidak diinginkan.
