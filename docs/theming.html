Theming

Atur identitas visual produk Anda lewat design tokens Minside CSS.

Theme Mode

Switch mode menggunakan atribut pada element html.

<html data-ms-theme="light">
...
</html>

Primary Tokens

TokenPurpose
--ms-primaryMain brand color
--ms-secondaryAlternative neutral action
--ms-info / --ms-success / --ms-warning / --ms-dangerSemantic colors
--ms-bg / --ms-bg-elevatedSurface colors
--ms-text / --ms-text-mutedTypography colors
--ms-font-heading / --ms-fontHeading/body font stacks

Typography Defaults

Framework mengarah ke Inter untuk heading dan Segoe UI untuk body text.

Pastikan font dimuat lewat Google Fonts atau self-host agar fallback tidak berubah drastis.

Custom Brand Example

:root {
  --ms-primary: #0d9488;
  --ms-primary-hover: #0f766e;
  --ms-secondary: #334155;
  --ms-bg: #f2f8f9;
}

[data-ms-theme="dark"] {
  --ms-bg: #0b1a24;
  --ms-bg-elevated: #122535;
}
