Introduction

Minside CSS adalah framework CSS modern dengan pendekatan minimalis: class jelas, visual tenang, dan komponen yang presisi untuk produk web nyata.

Why Minside CSS

Framework ini dibuat untuk tim yang ingin mempercepat UI delivery tanpa mengorbankan konsistensi visual dan keterbacaan codebase.

Clean

Class naming stabil, mudah dipelajari, mudah di-review.

Calm

Design token fokus ke ritme spacing, kontras, dan whitespace.

Precise

Komponen dan utilities dirancang agar predictable di produksi.

Quick Start

Mulai dengan CDN atau install package. Lihat detail lengkap di halaman Guides.

<link rel="stylesheet" href="../dist/minside.css" />
<script defer src="../dist/minside.js"></script>

<button class="ms-btn ms-btn-primary">Hello Minside</button>

What You Get

  • Layout primitives: container + responsive grid.
  • Rich component set: button, card, badge, table, modal, alert, dropdown, accordion, navbar.
  • Utility classes: spacing, text, color, flex, border, visibility helpers.
  • Theme-ready tokens dengan dukungan light/dark mode.
