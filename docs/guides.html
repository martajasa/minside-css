Installation Guides

Panduan langkah demi langkah untuk berbagai jenis proyek dan best practice setup.

Guide 1: Static HTML Project

  1. Copy file dist/minside.min.css dan dist/minside.min.js ke folder assets.
  2. Load CSS di <head> dan JS sebelum </body>.
  3. Mulai dari komponen dasar: .ms-btn, .ms-card, .ms-grid.
<link rel="stylesheet" href="assets/minside.min.css" />
...
<script defer src="assets/minside.min.js"></script>

Guide 2: Vite / React / Vue

  1. Install package: npm install minside-css.
  2. Import CSS + JS di entry file aplikasi.
  3. Jangan override token langsung di komponen, buat file theme terpisah.
import "minside-css/dist/minside.css";
import "minside-css/dist/minside.js";
import "./theme.css";

Guide 3: Laravel / Blade

Jika menggunakan Vite di Laravel, import Minside di resources/css/app.css atau entry JS sesuai setup.

/* app.css */
@import "minside-css/dist/minside.css";

Responsive Setup

Minside sudah responsif secara default pada grid utama. Gunakan helper berikut untuk kontrol visibilitas.

ClassBehavior
.ms-hidden-mobileDisembunyikan pada layar <= 900px.
.ms-hidden-desktopMuncul hanya pada layar <= 900px.

Production Checklist

  • Pakai file minified (minside.min.css, minside.min.js) di production.
  • Pin versi package/CDN.
  • Uji mode light + dark sebelum rilis.
  • Audit contrast untuk teks kecil.
