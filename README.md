# minside-css
Minside CSS is a lightweight front-end framework built with clarity and consistency in mind.
Designed for developers who want structured components without unnecessary complexity.

## ✨ Features
Component-based architecture
Utility-first helpers (spacing, flex, opacity, borders, colors)
Clean minimal design system
Vanilla JS interactive components
No dependencies
Easy to customize
Lightweight and fast

## 📦 Installation
Clone Repository
````bash
git clone https://github.com/martajasa/minside-css.git
cd minside-css
````

## 🚀 Quick Start
````bash
<!DOCTYPE html>
<html>
<head>
  <link rel="stylesheet" href="dist/minside.css">
</head>
<body>

  <div class="ms-container">
    <h1 class="ms-text-center">Hello Minside</h1>
    <button class="ms-btn ms-btn-primary">
      Get Started
    </button>
  </div>

  <script src="dist/minside.js"></script>
</body>
</html>
````

## 🧱 Components

● Buttons ● Cards ● Navbar ● Hero ● Tables ● Accordion ● Dropdown ● Carousel ● Modal ● Forms ● Lists ● Alerts ● Utilities (flex, spacing, borders, opacity, colors, etc.)

## 🎨 Design Philosophy
Minside CSS is built around:

✅ Minimalism over decoration ✅ Consistency over chaos ✅ Components over scattered utilities ✅ Readability over trend

It avoids heavy visual noise and focuses on clarity and structure.

## 🔎 Documentation
Since GitHub Pages is already used for another site, documentation can be:

✔ Hosted on custom domain ✔ Deployed via Vercel / Netlify ✔ Served locally ✔ Hosted inside subfolder of another domain

To preview locally:
````bash
cd docs
npx serve
````
or simply open docs/index.html in browser.
